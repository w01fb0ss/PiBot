# 2 · Bot 与角色

每个 Bot 有自己的名字、人设、模型、技能、权限和记忆。Pi 是默认的主 Bot；你可以按角色新建更多 Bot，让它们各管一摊事，也可以把几个 Bot 拉进群里分工（见 [6 · 群聊](06-groups.md)）。

## 新建 Bot

点左侧栏顶部的「＋」，选「新建 Bot」（快捷键 ⌘1 / Ctrl+1）。

![新建菜单](../images/zh/new-menu.png)

### 从角色新建

![选一个角色](../images/zh/role-picker.png)

「选一个角色」列出可用的角色，可以按分类（工程、产品与设计、数据与研究、内容与营销、办公与运营、通用）筛选或搜索。角色自带工作规范、技能和默认权限。全部角色：

- **工程**：后端开发、前端开发、全栈开发、代码审查员、DevOps / 运维、测试工程师、技术文档、小匠（制作插件）
- **产品与设计**：产品经理、UI / UX 设计师、生图设计师
- **数据与研究**：研究员、数据分析师、导师
- **内容与营销**：文案写手、新媒体运营、演示设计师、翻译、视频脚本
- **办公与运营**：个人助理、项目经理、招聘 / HR、主动助理
- **通用**：通用助手

安装包里自带常用的几个（如全栈开发、测试工程师、代码审查员、研究员、新媒体运营、演示设计师、小匠），离线也能用；其余角色和群聊模板放在**角色库**里，和自带的角色一起显示，第一次选用时联网下载，下载前会校验官方签名。列表上方的「检查角色库」「刷新角色库」用来拿到最新的角色和新版本。也可以在官网 [角色库](https://pibot.space/cn/roles/) 浏览全部角色和群聊模板，点「在 Pi Bot 中打开」直接添加（需要 0.0.3 或更高版本，添加前会请你确认）。

**主动助理**（小望）按你定的节奏查看日程和待办，只在有需要你处理的事时才提醒你，平时保持安静；它只读取和整理，不替你回复或改日程。邮件连接会在后续版本提供。

生图设计师需要先在 设置 › 模型与密钥 里配置一个能生图的模型，否则显示「暂不能创建」。

点一个角色后可以改名字、写补充描述（例如负责哪个项目，只作参考，不是指令），并看到它会用的模型、默认权限、自带技能和工作规范。确认后点「创建 Bot」。

![从角色新建 Bot](../images/zh/new-bot-from-role.png)

### 自己描述

列表最后的「通用（自己描述）」：写一段工作描述，Pi Bot 帮你生成名字和人设。

## Bot 资料面板

在聊天顶部点 Bot 的名字或头像，右侧打开资料面板。面板有四个标签：资料、话题、技能、权限。改动在离开输入框时自动保存。

### 资料

![资料](../images/zh/bot-profile.png)

- **名字、它的工作**：显示在侧栏和聊天里。
- **模型、思考强度**：新建 Bot 时默认用 设置 › 模型与密钥 里的默认模型。每个 Bot 可以单独选模型。思考强度有「关」「低」「中」「高」，只显示当前模型支持的档位。
- **来自角色**：从角色新建的 Bot 会标出角色和版本。
- **代码审查**：「默认请谁审查」决定改动面板里「请…审查」交给哪个 Bot（自动推荐先找「代码审查」角色的 Bot，再找用别的模型的 Bot）；「写完代码后自动请它审查」只在改了文件的回合生效，审查是只读的。
- **自动操作**：写入后运行格式化命令（执行仍按权限审批）；任务完成时通知（通知不含聊天正文）。
- **人设与工作规范**：分开编辑。
- **用过的文件夹**：这个 Bot 用过的工作文件夹。文件夹属于各个话题，在聊天顶部选择。
- **命令日志保留**：保留天数和大小上限，每个 Bot 独立设置。
- **运行上限（含费用上限）**：限制下一次运行。

### 话题

![话题](../images/zh/bot-topics.png)

这个 Bot 的例行任务（可以在这里「新建任务」）和全部话题，包括已归档和已导入的对话。

### 技能

![技能与记忆](../images/zh/bot-skills-memory.png)

- **技能**：这个 Bot 能用的技能和开关。在聊天里说一声就会用；停用的技能不会出现在它的提示里。「添加」可以给它加技能。
- **常用计划**：群里一次全部步骤都通过的计划，可以在完成消息上「保存为常用计划」，之后直接运行。
- **能用的连接**：它能用的应用和 MCP。
- **记忆**：见下文。

### 权限

![权限](../images/zh/bot-permissions.png)

默认跟随 设置 › 权限 里的全局权限，改过的会标出「已单独设置」，点「恢复」回到全局。还可以开关 Bot 浏览器的「Google 兼容模式」、清除浏览数据、查看操作记录。权限的含义见 [5 · 审批与权限](05-approvals-and-permissions.md)。

## 记忆

Bot 会记住你的偏好和约定，下次自动参考。记忆分四种，按「谁能用」区分：

| 记忆 | 谁能用 | 记什么 | 在哪里看和改 |
|---|---|---|---|
| **用户记忆**（关于你） | 所有 Bot，群聊里也能用 | 关于你本人的事：身份、个人偏好、习惯、沟通方式 | 左下角头像菜单 ›「关于你」 |
| **Bot 记忆** | 只有这个 Bot | 这个 Bot 的工作内容、做事方式、任务进展 | 这个 Bot 资料面板的「技能」标签 |
| **群记忆** | 只有这个群 | 这个群的分工、约定和工作内容 | 这个群资料面板的「技能」标签 |
| **项目记忆** | 在这个文件夹里工作的所有 Bot 和群 | 这个项目的约定、构建命令、目录结构 | 聊天顶部的文件夹菜单 ›「这个文件夹的项目记忆」 |

项目记忆跟着工作文件夹走：只有你选的项目文件夹才有，Bot 自己的目录和执行端上的文件夹没有。它只存在这台电脑上，不会写进项目文件。

Bot 记一条记忆时会自己选放在哪种里：关于你本人的放进用户记忆，项目的约定放进项目记忆（只在项目文件夹里工作时），其余的工作内容私聊时放进 Bot 记忆、群里放进群记忆。

![关于你](../images/zh/about-you.png)

怎么增加记忆：

- 和 Bot 聊天时说「记住我喜欢……」。
- 在记忆列表里点「＋ 添加」，写一条并选分类（关于你、工作、做事方式、其他）。
- 打开「自动从对话里提炼记忆」。切换话题、约 30 分钟没有新消息，或包含你参与的群计划、例行任务结束时，Pi Bot 会安排提炼。退出时待处理的提炼会保存，下次启动可以继续。

你也可以直接纠正 Bot，例如说「以后报告先写结论」。开启自动提炼和「直接记住」时，Pi Bot 会优先处理识别到的纠正和长期偏好。写入成功后，原回复下方会出现 **已记住**，可以在那里点 **撤销**。模型忙时可能要多等一会儿。选「先问我」时会先看到待确认的建议。

「学到新东西时」可以选「直接记住」或「先问我」。选「先问我」时，Bot 要写记忆会先请你确认。「关于你」里的「整理归位」会用模型把属于某个 Bot 工作范围的记忆归回那个 Bot，生成的移动建议出现在「待办」里，由你逐条确认。

记忆只存在这台电脑上，随时可以修改或删除。每次运行的工作收据会列出这次用了哪些记忆（见 [3 · 聊天](03-chatting.md#工作收据)）。

## 外部 Agent

电脑上已经装好的编程助手（Codex、Claude Agent、Cursor、OpenCode、Antigravity，或任何支持 ACP 的 agent）可以作为 Bot 加入 Pi Bot。在「选一个角色」里选「外部 Agent」分类，Pi Bot 会查看这台电脑上装了哪些（只看程序路径和版本，不读它们的账号和对话），点一个后按「把 … 加为 Bot」的说明创建。

- 它用自己的登录和计费，Pi Bot 不读、不保存它的令牌。
- 它在 Pi Bot 的沙箱里运行，只能写这个话题的工作文件夹；Windows 上没有命令沙箱，卡片会标「不隔离运行」。
- 登录失效或额度用完时会提前显示：资料页和聊天里出现「需要登录」或「套餐受限」，写明在终端运行哪条登录命令（可以「复制命令」），处理好后点「重新检查」，不用等它真的运行失败。

## 导入与分组

![从侧栏「＋」打开导入和分组选项](../images/zh/new-menu.png)

- **从 .pibot 文件导入**：「＋」›「从 .pibot 文件导入」，先预览再导入。多 Bot 或群聊模板会按预览整体导入。
- **新分组**：「＋」›「新分组」，用来整理侧栏。

## 让 Pi 管理 Bot 和派活

默认的 Pi 是你的总助：在和 Pi 的私聊里说「帮我配一个管账的」「建个群，把小财和小码拉进来」「让小审核对一下合同」，Pi 可以替你新建、修改、归档或恢复 Bot，建群、加减群成员、归档或恢复群组，也可以把一件事派给某个 Bot 或群组。

- 需要确认时，卡片会写明要改什么，或把任务派给谁。勾选「以后不再问」会把 Pi 权限页里对应的一项改成「总是允许」。在 Pi 的话题里打开 YOLO 可以跳过允许自动确认的卡片。设为「不允许」的仍然不做。
- Pi 的「权限」标签页最上面有「管理、派活、修复和设置 · 只有 Pi 有」：「管理 Bot 和群组」「给 Bot 和群组派活」「检查和修复卡住的状态」「修改设置」四项都可以设为不允许、询问（默认）或总是允许。别的 Bot 没有这几项，也拿不到这些工具。
- Pi 可以归档和恢复 Bot 或群组，不能删除。要改设置或权限，见[让 Pi 修改设置](#让-pi-修改设置)。
- 派出去的活会在对方那里开一个标着「来自 Pi」的新话题，对方按自己的权限做；群组按群的正常流程由协调者安排。做完、失败、停止或等你确认时，Pi 的聊天里会出现回执卡（结果、摘要、产出，可以「打开话题」），Pi 再用一两句话告诉你。
- 一轮最多派 3 次活；被派活的 Bot 或群不能再接着派活，也不能派回给 Pi。
- 这些只在和 Pi 的私聊里可用：在电脑上，或在已配对的手机上发给 Pi（卡片和回执在手机上同样能看、能处理，也能勾「以后不再问」）。手机离线时用自己的模型、编辑器（ACP）、群聊、例行任务里都没有。

## 让 Pi 修改设置

在和默认 Pi 的私聊里，可以让它查看或修改设置，比如「切到深色模式」或「把小码的模型换一下」。Pi 会先核对当前值。需要确认时，卡片会显示改动前后的值。改动走和设置界面相同的流程，也会写进操作记录。

- **普通设置**包括语言、外观、聊天字号、灵动岛、托盘图标、例行任务睡眠与离开规则、自动整理记忆和记忆预算。Pi 也能修改 Bot 的模型、思考强度、记忆选项和当前工作文件夹。它还能修改图片 Bot 的生成方式，以及已安装连接中可编辑的非敏感配置。切换到项目文件夹时，话题必须空闲，文件夹也要事先为这个 Bot 在本机设好。
- **普通设置的审批**由 Pi 的「修改设置」权限决定，默认是「询问」。批准卡片时，勾选「以后直接允许 Pi 修改普通设置」可改为「总是允许」。设为「总是允许」或在 Pi 的话题打开 YOLO 后，普通设置可以直接修改。
- **安全设置**包括全局和单个 Bot 的权限级别、命令联网与允许的网站、撤销 Bot 已记住的授权，以及让 Bot 每次对外发送都先询问。Pi 也可以改受支持系统上的沙箱设置、手机连接设置、浏览器扩展选项和「仅用本地模型整理记忆」。对于连接，Pi 可以修改可用范围、确认方式、允许的域名和工具权限。Pi 可以提议开关自己当前话题的 YOLO。要给其他话题开关 YOLO，请用对应话题的标题栏。
- **安全设置的审批**每张卡片只列一项改动，并附风险说明。每次都要你亲自确认。「总是允许」和 YOLO 都不会跳过卡片，审批也不能记住。
- 将「修改设置」设为「不允许」会禁止通过此功能修改任何设置。Pi 仍可查看受支持的设置，包括模型凭据是否已配置。此功能不能读取或修改密钥、密码、令牌和已保存的登录账号，请在设置中管理。在电脑上，拒绝凭据请求的提示可能带有「打开设置」按钮。
- Pi 可以移除已记住的沙箱例外，也可以撤回 Windows 的 YOLO 同意。要新增这类例外或授予 Windows YOLO 同意，请用应用内的对应操作。Pi 只能提议修改允许范围内的设置。
- 保存前，Pi 会再次比对当前值。如果设置已改动，Pi 会停下。这个功能可以在电脑上使用，也可以从连接到电脑的已配对手机使用。手机离线模式、ACP 编辑器、群聊、例行任务、无人值守运行和执行端上不能用。

## 让 Pi 检查和修复卡住的状态

某个 Bot 或群一直「等你处理」、发不出消息、计划停着不动、连接连不上时，在和 Pi 的私聊里说「我的群卡住了」或「帮我看看小码怎么了」。Pi 先体检（只读，不改任何东西，可以只查一个 Bot 或群），在回复里列出卡住的每一项：在哪、从什么时候起、为什么卡住、建议怎么修。什么都没查到就直接告诉你一切正常。

Pi 会查这些：接不上的审批卡（后面已经有了新的对话，或者没有运行在等它）；显示「运行中」但已经没有进程的运行、一直排队没人启动的运行；不接新消息但后面没有在跑的话题；在等你选择的计划和卡住的步骤（继续剩下的步骤、按现状接受、重试或跳过、结束计划）；很久没有动静的任务；连接出错的连接；进程已经不在的后台命令。

- 点列表里某一项下面的修法（比如「停止这次运行」「按剩下的步骤继续」），或者直接告诉 Pi 修哪一项。你同意修哪一项，Pi 才会修，每次都会先弹卡片写明会改什么、什么不能撤销。修法和应用里自己的按钮走同一条路，不会直接改数据库或数据文件，也不会删除 Bot、群组、消息或快照。
- 修之前 Pi 会再查一次；如果这期间状态变了，会告诉你「状态已经变了，请重新体检」，什么都不改。
- 「检查和修复卡住的状态」设为「总是允许」或打开 YOLO 后，普通的修复不再弹卡片；但停止还有进程在跑的运行、结束计划、关闭任务每次都要你确认。
- 每次体检（只记数量）和每次修复都会写进审计记录。
- 和上面一样，只在和 Pi 的私聊里可用（电脑上，或已配对的手机通过电脑）。数据库本身损坏不在修复范围内：看到这种情况请用备份恢复。
