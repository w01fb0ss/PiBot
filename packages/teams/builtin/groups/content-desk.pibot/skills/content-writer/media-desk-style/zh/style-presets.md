# 博主写作风格预设（8 板块 15 套）

改编自 `woniuniuniu/dsh-media-desk` (`src/style-presets.js`, MIT)。用户无现成样稿时可先选一套，再按个人习惯修改。

## 科技数码

### 1. AI 科技博主（`ai_tech`）
- **整体**：把复杂的技术讲成一个能听懂的比喻，再告诉你跟你有什么关系。
- **语气**：好奇、清醒，兴奋但不吹嘘，遇到没验证的说法会直说。
- **句式**：短句为主，先结论后解释，专业词后面马上跟一句人话。
- **开头**：用一个刚发生的变化开场，三秒内说清楚它为什么值得看。
- **结构**：发生了什么 → 用比喻讲原理 → 我亲手试的结果 → 对普通人意味着什么。
- **常用词**：说白了、我试了一下、关键在于、这意味着
- **绝不要**：颠覆、炸裂、遥遥领先、没有实测就下结论
- **样句**：
  - 说白了，它不是变聪明了，是终于记得住你刚才说过什么了。
  - 我试了一下，前十分钟很惊艳，第十一分钟开始胡说。

### 2. 数码测评博主（`gadget`）
- **整体**：不念参数，只讲用了两周之后，哪里真香，哪里想退货。
- **语气**：实在、有点挑剔，站在花自己钱的人这边。
- **句式**：数字和体验成对出现，常用对比，少用形容词。
- **开头**：直接给结论：谁该买，谁别买。
- **结构**：一句话结论 → 最好的一点 → 最烦的一点 → 跟上一代或竞品比 → 购买建议。
- **常用词**：实测、续航、值不值、谁该买、谁别买
- **绝不要**：旗舰体验、越级、照抄宣传语
- **样句**：
  - 实测一天两充，厂商写的三十小时，大概只在说明书里成立。
  - 如果你手上这台还能用，这代真的可以跳过。

## 旅行探店

### 3. 旅行博主（`travel`）
- **整体**：不列攻略清单，带你站到那个地方，再把真正有用的细节交给你。
- **语气**：松弛、有画面感，会讲踩过的坑。
- **句式**：长短句交替，多写看到、听到、闻到的东西，实用信息写得很具体。
- **开头**：从一个具体的瞬间开场，比如清晨六点的码头。
- **结构**：一个瞬间 → 为什么来这里 → 三个真正值得的地方 → 踩过的坑 → 时间和花费。
- **常用词**：那天、本地人、人均、提前订、绕开
- **绝不要**：人间仙境、此生必去、宝藏小众
- **样句**：
  - 那天早上六点的码头没有游客，只有卸鱼的声音和一碗烫嘴的粉。
  - 人均一百二，但要绕开门口那家，本地人都往巷子里走。

### 4. 美食探店博主（`food`）
- **整体**：一口下去是什么感觉，值不值这个价，排队多久，全都说清楚。
- **语气**：馋、真诚，好吃就夸，不好吃也会说。
- **句式**：口感词要具体，短句带节奏，价格和位置必须写。
- **开头**：从最想吃的那一口开场。
- **结构**：招牌那一口 → 店在哪、多少钱、排多久 → 必点和不用点 → 一句话评价。
- **常用词**：这一口、人均、排队、不用点、会再来
- **绝不要**：绝绝子、好吃到哭、只夸不评
- **样句**：
  - 这一口是焦脆的，咬开之后油香才慢慢出来。
  - 人均六十，排了四十分钟。味道值，排队不值，建议两点以后去。

## Vlog 生活

### 5. Vlog 日常博主（`vlog`）
- **整体**：像朋友带着镜头过一天，琐碎、有趣，结尾留一点小感受。
- **语气**：亲近、自然，可以自嘲，不端着。
- **句式**：口语化，像边走边说，多用「然后」「结果」，可以有停顿。
- **开头**：从今天一件小事或小意外开场。
- **结构**：今天的小意外 → 按时间走完这一天 → 中间一个小转折 → 结尾一句当下的感受。
- **常用词**：今天、然后、结果、没想到、还挺好的
- **绝不要**：宝子们、说教、强行升华
- **样句**：
  - 今天本来只想下楼拿个快递，结果在楼下坐了一个小时。
  - 没发生什么大事，但这一天还挺好的。

### 6. 独居家居博主（`home`）
- **整体**：把普通的房间和日子拍得舒服，也把花了多少钱老实告诉你。
- **语气**：安静、温和，有分寸的生活感。
- **句式**：句子短而轻，多写光线、声音和习惯，少用感叹号。
- **开头**：从一个固定的日常动作开场，比如每天早上开窗。
- **结构**：一个日常动作 → 空间或物件的小改变 → 花费和做法 → 它带来的感受。
- **常用词**：慢慢、光线、顺手、花了、刚刚好
- **绝不要**：精致生活、仪式感、贩卖焦虑
- **样句**：
  - 下午四点，光刚好走到这张桌子上。
  - 这张桌子花了三百块，不贵，但让我开始愿意在家吃饭了。

## 观点认知

### 7. 读书笔记博主（`reading`）
- **整体**：不复述全书，只讲一个改变你想法的观点，再落到一件能做的事。
- **语气**：沉静、诚恳，讲自己怎么被一本书说服。
- **句式**：先讲生活里的困惑，再引一句原文，解释时用短句。
- **开头**：从一个具体的困惑开场，再引出这本书。
- **结构**：我遇到的困惑 → 书里的一个观点 → 一个例子 → 今天可以做的一件事。
- **常用词**：这本书、我才意识到、换句话说、可以试试
- **绝不要**：读完这本书你就能、干货满满、复述目录
- **样句**：
  - 读到这一页我才意识到，我不是没时间，是一直不肯放弃任何一件事。
  - 换句话说，先决定不做什么，今天就可以试试。

### 8. 职场成长博主（`career`）
- **整体**：观点先行，用真实经历讲透一个职场道理，敢说大家心照不宣的话。
- **语气**：直接、清醒，有一点锋利，但不刻薄。
- **句式**：断言式短句，常用反问和对比，例子要具体到场景。
- **开头**：开口就否定一个大家都信的说法。
- **结构**：反直觉观点 → 我亲历的场景 → 背后的逻辑 → 一个可以照做的动作。
- **常用词**：别再、真相是、我见过、下次开会
- **绝不要**：打工人加油、贩卖焦虑、空洞的鸡汤
- **样句**：
  - 别再说你只是不会向上管理了，你是一直在等别人先看见你。
  - 真相是，会议结束前没人认领的事，就是没人会做。

## 干货教程

### 9. 工具教程博主（`tutorial`）
- **整体**：先给你看结果，再一步一步带着做，每步都说清楚容易错在哪。
- **语气**：耐心、利落，像坐在旁边手把手教的朋友。
- **句式**：动词开头的短句，步骤清楚，一步只做一件事。
- **开头**：先展示做完的结果和节省的时间。
- **结构**：最终效果 → 需要准备什么 → 分步操作 → 最容易出错的地方 → 下一步可以怎么玩。
- **常用词**：第一步、点这里、注意、做完之后、省了
- **绝不要**：很简单、大家都会、跳步骤
- **样句**：
  - 做完之后是这个效果，原来要两小时的活，现在三分钟。
  - 注意这一步别点确定，先检查右上角的格式，九成的错都出在这。

### 10. 商业拆解博主（`business`）
- **整体**：从一个现象入手，拆清楚钱从哪来、算得过来吗，以及你能学到什么。
- **语气**：冷静、笃定，用数字说话，不煽情。
- **句式**：短句，一句只说一件事，多用数字和对比，推测要标明。
- **开头**：用一个反常的数字或现象开场。
- **结构**：反常现象 → 它怎么赚钱 → 算一笔账 → 风险在哪 → 普通人能学什么。
- **常用词**：算一笔账、毛利、说到底、可以学的是
- **绝不要**：风口、财富密码、稳赚、投资建议
- **样句**：
  - 一杯卖九块九还能开一万家店，先算一笔账。
  - 说到底，它赚的不是咖啡的钱，是把房租摊薄的钱。

## 种草测评

### 11. 美妆护肤博主（`beauty`）
- **整体**：说清楚适合什么肤质、用多久见效、有没有更便宜的替代。
- **语气**：亲近、实在，像闺蜜说真话。
- **句式**：肤感和效果写具体，常用「适合」「不适合」，推荐要有依据。
- **开头**：从一个具体的皮肤问题或翻车经历开场。
- **结构**：我的肤质和问题 → 用了什么、用了多久 → 真实效果 → 不适合谁 → 平替。
- **常用词**：肤质、上脸、用了两周、不适合、平替
- **绝不要**：烂脸救星、一夜回春、医疗功效的承诺
- **样句**：
  - 混油皮，用了两周，下午的泛油确实少了，但闭口没变化。
  - 敏感肌先别冲，这瓶酒精靠前，上脸有点刺。

### 12. 穿搭博主（`outfit`）
- **整体**：不只说好看，还告诉你什么身材能穿、怎么搭、一件能穿几个季节。
- **语气**：轻快、有主见，审美明确但不居高临下。
- **句式**：短句，身高体重和尺码写清楚，搭配说到具体单品。
- **开头**：从一个穿衣场景或常见的显胖难题开场。
- **结构**：场景或难题 → 这一身怎么搭 → 为什么这样显比例 → 尺码和价格 → 换一种穿法。
- **常用词**：显比例、我穿、通勤、一衣多穿、可以换成
- **绝不要**：显瘦十斤、身材焦虑、必入
- **样句**：
  - 我一米六二穿 M，腰线提高三厘米，比例一下就出来了。
  - 这件通勤穿，周末换条牛仔裤也不违和。

## 情感故事

### 13. 情感故事博主（`story`）
- **整体**：像深夜跟朋友聊天，从一件小事讲到一个想明白的道理。
- **语气**：松弛、真诚，愿意讲自己的糗事，不下判断。
- **句式**：长短句交替，有口语停顿，细节多，结论少。
- **开头**：从一个具体的时间和场景开场。
- **结构**：一个场景 → 当时发生了什么 → 我当时没明白的事 → 后来想通的一句话。
- **常用词**：那天、后来我才发现、其实、说实话
- **绝不要**：懂的都懂、人生导师口吻、贬低任何一方
- **样句**：
  - 那天晚上十一点，我们坐在车里，谁都没先开口。
  - 后来我才发现，她要的不是答案，只是有人听完。

### 14. 亲子成长博主（`parent`）
- **整体**：记录孩子的一句话和一件小事，再讲家长自己学到了什么。
- **语气**：温柔、幽默，不焦虑，也不把自己当标准答案。
- **句式**：口语、短句，保留孩子的原话，方法要具体可试。
- **开头**：从孩子说的一句话开场。
- **结构**：孩子的一句话 → 当时我的反应 → 我查到或试过的方法 → 后来的变化。
- **常用词**：今天他说、我当时、试了一下、不一定适合每个孩子
- **绝不要**：别让孩子输在、正确的育儿、医疗诊断
- **样句**：
  - 今天他说，妈妈你生气的时候，声音会变小，我更害怕。
  - 试了一下先蹲下来再说话，不一定适合每个孩子，但我们家有用。

## 热点资讯

### 15. 热点快评博主（`news`）
- **整体**：一分钟讲清发生了什么，分清事实和观点，再说一个别人没提的角度。
- **语气**：利落、中立，有判断但不带节奏。
- **句式**：短句快节奏，时间和来源要明确，事实和观点分开说。
- **开头**：第一句话就说清发生了什么。
- **结构**：发生了什么 → 已确认的和还不确定的 → 为什么大家在吵 → 我的一个角度。
- **常用词**：目前能确认的是、还不确定、来源、我的看法是
- **绝不要**：震惊、细思极恐、把传闻当事实
- **样句**：
  - 目前能确认的只有两件事，其他都还只是传闻。
  - 大家都在吵谁对谁错，我的看法是，先看合同第三条。
